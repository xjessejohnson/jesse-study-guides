The Certified Information Systems Security Professional (CISSP) is a globally recognized certification issued by (ISC)². Using Computerized Adaptive Testing (CAT) with 100 to 150 questions and a minimum passing score of 700 out of 1000, it evaluates mastery across eight core security domains.

1. Security & Risk Mgmt 16%
2. Asset Security 10%
3. Architecture & Eng 13%
4. Comm & Network Sec 13%
5. IAM 13%
6. Assessment & Testing 12%
7. Security Operations 13%
8. Software Dev Sec 10%
